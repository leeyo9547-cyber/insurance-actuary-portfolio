# Insurance Actuarial Portfolio

보험계리 및 보험 데이터 분석 직무를 목표로 보험수리, SQL, Python, Excel, IFRS17 및 K-ICS 관련 프로젝트를 정리하는 포트폴리오입니다.

## Repository Structure

| Path | Purpose |
|---|---|
| `01_Actuarial_Valuation/` | 생명보험 보험료·준비금 및 보험수리 계산 프로젝트 |
| `02_Insurance_SQL_Analysis/` | 보험계약·보험료·보험금 데이터 SQL 분석 프로젝트 |
| `03_IFRS17_Model/` | IFRS17 현금흐름·BEL·RA·CSM 관련 미니 모델 |
| `04_KICS_ALM/` | K-ICS, 금리리스크, 듀레이션 및 ALM 프로젝트 |
| `05_Automation/` | Excel/VBA/Python 기반 반복업무 및 검증 자동화 |
| `datasets/` | 프로젝트에서 사용하는 공개·가상 데이터 |
| `docs/` | 공통 설명자료, 설계 문서 및 결과 요약 |

## Core Tools

- Excel / VBA
- SQL
- Python
- Actuarial Mathematics
- IFRS17 / K-ICS

Projects will be added progressively.
