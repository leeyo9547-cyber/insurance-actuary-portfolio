# Insurance Actuarial Portfolio

수학적 보험계리 모델링 역량을 중심으로 Pricing, Reinsurance, Risk/Capital, Valuation까지 연결하고, IFRS17·K-ICS 및 데이터 엔지니어링을 실무 적용 계층으로 확장하는 포트폴리오입니다.

장기적으로 재보험사 및 글로벌 계리 시장에서 통용되는 정량적 모델링 역량을 구축하는 것을 목표로 합니다.

## Repository Structure

| Path | Purpose |
|---|---|
| `01_Actuarial_Modeling/` | 생명보험수리, 손실모형, 생존모형 등 계리수학 기반 모델링 |
| `02_Pricing_Experience_Studies/` | Frequency-Severity, GLM Pricing, Experience Study, Credibility |
| `03_Reinsurance_Modeling/` | Excess of Loss, Stop Loss, Treaty Pricing, Aggregate Loss 모델링 |
| `04_Risk_Capital_Modeling/` | Monte Carlo, VaR/TVaR, Stress Testing, Dependency Modeling, ALM |
| `05_Valuation_Reserving/` | 준비금, 현금흐름 Projection, 민감도 및 부채평가 모델 |
| `06_IFRS17_KICS/` | IFRS17, K-ICS 및 지급여력·회계·규제 적용 |
| `07_Data_Engineering_Automation/` | SQL, Python, Excel/VBA를 활용한 데이터 처리·검증·자동화 |
| `datasets/` | 프로젝트에서 사용하는 공개·가상 데이터 |
| `docs/` | 공통 설명자료, 모델 설계 문서 및 결과 요약 |
