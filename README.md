# Insurance Actuarial Portfolio

IFRS17·K-ICS 실무 프레임워크에서 시작해 Valuation/Reserving, Actuarial Modeling, Pricing, Reinsurance, Risk/Capital Modeling으로 확장하는 보험계리 포트폴리오입니다.

학습·실습 순서는 보험회사 실무 이해에서 출발하되, 장기적으로는 재보험사 및 글로벌 계리 시장에서 통용되는 수학적·정량적 모델링 역량을 구축하는 것을 목표로 합니다.

## Repository Structure

| Path | Purpose |
|---|---|
| `01_IFRS17_KICS/` | IFRS17, K-ICS 및 지급여력·회계·규제 적용 |
| `02_Valuation_Reserving/` | 준비금, 현금흐름 Projection, 민감도 및 부채평가 모델 |
| `03_Actuarial_Modeling/` | 생명보험수리, 손실모형, 생존모형 등 계리수학 기반 모델링 |
| `04_Pricing_Experience_Studies/` | Frequency-Severity, GLM Pricing, Experience Study, Credibility |
| `05_Reinsurance_Modeling/` | Excess of Loss, Stop Loss, Treaty Pricing, Aggregate Loss 모델링 |
| `06_Risk_Capital_Modeling/` | Monte Carlo, VaR/TVaR, Stress Testing, Dependency Modeling, ALM |
| `07_Data_Engineering_Automation/` | SQL, Python, Excel/VBA를 활용한 데이터 처리·검증·자동화 |
| `datasets/` | 프로젝트에서 사용하는 공개·가상 데이터 |
| `docs/` | 공통 설명자료, 모델 설계 문서 및 결과 요약 |
