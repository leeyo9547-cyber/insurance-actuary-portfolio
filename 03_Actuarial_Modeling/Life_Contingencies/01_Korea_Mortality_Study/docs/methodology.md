# Methodology

## 1. 핵심 정의

연령 x의 1년 사망확률을 q_x라 하면,

p_x = 1 - q_x

는 1년 생존확률입니다.

n년 생존확률은

{}_n p_x = p_x p_{x+1} ... p_{x+n-1}

로 계산합니다.

기수 l_0 또는 특정 시작연령의 l_x를 정하면,

l_{x+1} = l_x p_x

d_x = l_x q_x

로 생존자수와 사망자수를 구성할 수 있습니다.

현재 실행 코드 `src/build_life_table.py`는 남녀 각각 l0=100,000으로 시작해
0~99세의 px, lx, dx를 계산합니다. qx는 2024년의 연령별 사망확률이며,
미래에도 이 연령별 확률이 유지된다는 기간 생명표 가정으로 생존확률을 구합니다.
사망률 개선과 개인별 건강상태는 반영하지 않습니다.

검증 관계:
- qx + px = 1
- lx - dx = l(x+1), lx는 비음수이며 연령에 따라 증가하지 않음
- 0~99세 dx 합계 + l100 = 100,000
- 생존확률의 연속 곱 = l(x+n) / lx (lx가 양수인 경우)

생존확률은 qx부터 q(x+n-1)까지만 사용합니다. 종료연령 x+n의 qx는 포함하지 않습니다.
q99로 l100을 계산할 수 있으므로 x+n <= 100까지 가능하지만,
개방연령구간의 값을 q100으로 사용하거나 100세 이후로 연장하지 않습니다.

저장 정밀도는 qx/px 소수점 5자리, lx/dx 6자리, n년 생존확률 12자리입니다.
검증은 저장용 반올림 전에 수행하며, 저장된 lx/dx의 관계에는 미세한 반올림 오차가 있습니다.

## 2. 데이터 비교 원칙

KOSIS 완전생명표와 보험개발원 경험생명표는 모집단이 다릅니다.

- KOSIS: 국민 전체의 사망경험을 기반으로 한 국가 생명표
- 보험개발원 경험생명표: 보험가입자 집단의 경험을 보험요율 산출 목적으로 정리한 표

따라서 차이를 데이터 오류로 간주하지 않고 모집단·선택효과·작성 목적 차이로 해석합니다.

## 3. 1차 비교

동일 연령에서 다음 값을 계산합니다.

difference = qx_kidi - qx_kosis

ratio = qx_kidi / qx_kosis

성별·연령별로 difference와 ratio를 확인하되, 표의 회차·연도 차이를 명시합니다.

## 4. 정기보험 예제

예: 가입연령 x, 보험기간 n년, 사망보험금 1을 연도말 지급한다고 가정합니다.

순일시보험료의 기본형:

A = Σ(v^(k+1) * {}_k p_x * q_{x+k}),  k=0,...,n-1

v = 1 / (1 + i)

연납 순보험료는 보험료 납입시점의 생존연금현가로 나누어 계산합니다.

## 5. 민감도

최소 다음 두 축을 분석합니다.

- 사망률: base, +10%, -10%
- 할인율: base, +100bp, -100bp

qx에 충격을 줄 때 0 <= qx <= 1 범위를 유지합니다.

## 6. 주의사항

보험개발원 공개 화면의 5세 간격 제9회 경험생명표 예시값은 비교용입니다.
1세별 보험료 산출에는 완전한 연령별 위험률 테이블이 필요합니다.
