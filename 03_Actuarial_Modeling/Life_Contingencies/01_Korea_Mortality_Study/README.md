# Korea Mortality Study

국내 공식 공개자료를 이용해 사망률을 검증·비교하고, 생명보험 계리 계산으로 연결하는 프로젝트입니다.

## 프로젝트 목표

1. KOSIS 완전생명표의 성별·연령별 사망확률(qx)을 정리한다.
2. 보험개발원이 공개하는 경험생명표 예시 사망률과 동일 연령에서 비교한다.
3. qx → px → 생존확률 → 생명표 함수를 계산한다.
4. 단순 정기보험의 보험금 현가와 순보험료를 계산한다.
5. 사망률과 할인율 변화에 대한 민감도를 분석한다.

## 데이터 원칙

- 실제 개인 계약자료나 개인정보는 사용하지 않는다.
- 공식 기관이 공개한 집계·참조자료만 사용한다.
- 원자료는 수정하지 않고 raw/에 보존한다.
- 변환 과정과 가정은 docs/에 남긴다.
- 보험개발원 현재 공개 페이지는 제10회 경험생명표의 적용시점과 평균수명을 안내하지만, 연령별 사망률 예시표는 제9회 경험생명표로 표시되어 있으므로 버전을 구분한다.

## 공식 데이터 출처

### KOSIS 완전생명표
- 기관: 국가데이터처(KOSIS)
- 통계표: 완전생명표(1세별, 전국)
- 통계표 ID: DT_1B42
- 프로젝트 기준연도: 2024
- 핵심 항목: 사망확률(qx), 생존자수(lx), 사망자수(dx), 기대여명(ex)

### 보험개발원 경험생명표
- 기관: 보험개발원
- 페이지: 참조순보험요율 예시
- 공개 페이지의 연령별 사망률 표: 제9회 경험생명표
- 본 저장소의 CSV는 화면에 공개된 5세 간격 예시값을 전사한 비교용 자료다.
- 이 자료만으로 1세별 보험료를 산출하지 않는다.

## 디렉터리

- data/raw/: 공식 원자료 또는 공식 페이지에서 전사한 비교용 원자료
- data/processed/: 분석용 표준화 데이터
- docs/: 출처, 정의, 가정, 분석 방법
- src/: 재사용 가능한 계산 코드
- results/: 결과표와 요약

## Day 1

1. data/raw/kidi_9th_experience_sample.csv를 검토한다.
2. KOSIS에서 2024 완전생명표(DT_1B42)를 내려받는다.
3. 원파일은 data/raw/에 그대로 저장한다.
4. KOSIS qx의 단위와 성별·연령 범위를 확인한다.
5. 0, 5, 10, ..., 100세에서 KOSIS와 보험개발원 값을 비교할 수 있는 표를 만든다.

## 완료 기준

- 데이터 출처와 버전을 재현 가능하게 기록한다.
- qx, px, lx, n년 생존확률을 계산한다.
- 국민 생명표와 보험가입자 경험 사망률의 차이를 연령·성별로 설명한다.
- 최소 하나의 정기보험 예제로 순보험료를 계산한다.
- 사망률 및 할인율 민감도 결과를 제시한다.
