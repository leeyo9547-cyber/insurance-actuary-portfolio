# Day 1: 중복 번호와 계약번호 연결 점검

목표는 원본을 보존하면서 점검 결과와 처리 근거를 남기는 것입니다. 예상 작업 시간은 30~45분입니다.

## 1. 실습 파일 열기

`01_policy_claims_practice.xlsx`를 열고 작업용 사본을 저장하세요. 기준일은 2026-09-30입니다. `계약`은 1,000행, `보험금`은 200행이며, 두 시트 모두 4행이 제목이고 5행부터 데이터가 시작합니다. 원본은 계약 A:E와 보험금 A:F이며, 작성할 점검 열은 연노랑입니다.

[프로젝트 폴더의 Excel 실습 파일](../01_policy_claims_practice.xlsx)을 다운로드해 사용할 수 있습니다. CSV만으로 시작하려면 빈 Excel 파일에 `계약`, `보험금` 시트를 만들고, 각 CSV의 제목과 자료를 A4부터 붙여넣으세요. 계약은 A:E, 보험금은 A:F가 원본입니다. 날짜와 지급액의 자료형은 데이터 사전을 참고하고, 필요한 점검 열을 오른쪽에 추가하세요.

## 2. 계약번호 중복 확인

`계약` 시트의 F5에 다음 수식을 입력하고 F1004까지 채우세요.

```excel
=IF(B5="","",COUNTIFS($B$5:$B$1004,B5))
```

F열에서 2 이상을 필터링하세요. 중복에 해당하는 모든 행을 `실습` 시트의 발견 내역에 기록하세요. `record_id`는 원본 행을 식별하는 번호이므로 계약번호와 함께 남기세요.

## 3. 보험금번호 중복 확인

`보험금` 시트의 H5에 같은 방식으로 수식을 작성하고 H204까지 채우세요.

```excel
=IF(B5="","",COUNTIFS($B$5:$B$204,B5))
```

H열의 2 이상 행을 기록하세요. 계약 하나에 보험금 여러 건이 있는 것은 정상일 수 있습니다. 보험금번호 중복과 계약번호 반복을 구분하세요.

## 4. 빈 계약번호와 연결 건수 확인

`계약`의 G5에는 `=IF(B5="",1,0)`을 입력하고 아래로 채우세요.

`보험금`의 I5에는 `=IF(C5="",1,0)`을 입력하고 아래로 채우세요.

`보험금`의 J5에는 다음 수식을 입력하고 J204까지 채우세요.

```excel
=IF(C5="","",COUNTIFS('계약'!$B$5:$B$1004,C5))
```

- 계약번호가 빈 행은 먼저 별도로 기록합니다.
- J열이 0이면 계약 자료에서 해당 번호를 찾을 수 없습니다.
- J열이 1이면 계약 행 하나와 연결됩니다.
- J열이 2 이상이면 계약 자료의 중복 키 때문에 연결이 모호합니다. 날짜나 상품을 첫 번째 행에서 임의로 가져오지 마세요.

## 5. 결과 기록

`실습` 시트에서 점검별 발견 행 수를 작성하세요. 발견 행 수는 점검 규칙별로 셉니다. 한 행이 여러 규칙에 해당할 수 있으므로 서로 다른 규칙의 행 수를 더해 전체 오류 행 수라고 부르지 않습니다.

발견 내역에는 자료명, record_id, 점검 항목, 관찰한 값, 처리 방안, 이유를 적으세요. 중복 자료는 먼저 확인 필요로 분류하세요. 실제 계약번호나 수정값을 원본만으로 확정할 수 없으면 임의로 고치지 않습니다.

오늘 제출할 내용은 점검별 발견 행 수와 연결 건수가 2 이상인 보험금의 처리 의견 한 문장입니다. 날짜·금액 점검과 상품별 집계는 이후 단계에서 진행합니다.
